### week01：坐标、变换与模型观察

- **承接与前置**：从参数化矩形进入长方体；会使用 C++ 类和基本三角函数，借助模板完成运行和模型观察。
- **目标**：区分点、向量、方向和坐标系；能预测刚体变换及其顺序的结果，区分模型数据变化与相机变化。
- **本周边界**：熟悉框架入口和 OCCT 变换调用；拓扑统计先作为观察结果，去重及共享机制在 week03 展开。

**本周五题：**

1. 点、向量和方向分别表示什么，为什么不能混用？
2. 坐标系怎样定义位置，局部坐标与世界坐标有什么关系？
3. 平移、旋转与相机操作分别改变什么？长度和角度采用什么约定？
4. 变换顺序、旋转轴和旋转中心为什么会影响结果？
5. 怎样通过坐标、体积及 BREP 保存重载证明变换正确？

**独立练习**：以世界原点为起点，建立沿 X/Y/Z 的 40×30×20 mm 长方体。分别执行“沿世界 X 轴平移 50 mm，再绕世界原点 Z 轴按右手规则旋转 90°”与相反顺序；先预测原始顶点 P=(40,0,0) 的位置，再观察坐标、体积和保存重载结果。另改变相机进行对照。界面角度以度输入，调用几何接口前转为弧度；不引入单位系统依赖。

**验收**：两种顺序中 P 分别约为 `(0,90,0)` 和 `(50,40,0)`，两者体积均约为 `24000 mm³`；相机操作不改变模型坐标和导出后的几何。比较坐标允许 `1e-9 mm` 数值误差，此阈值仅用于本练习，不用于修改模型容差。留下原始/变换模型、关键点与体积对照及 BREP 重载记录，不要求 BREP 文件逐字节相同。

**下一周动机**：能说明对象放在哪里之后，进一步读取曲线、曲面自身的参数表示，解释模型上的点和方向怎样算出。

### week02：曲线、曲面与参数采样

- **承接与前置**：已有 week01 的坐标系、变换、单位约定和观察能力；按采样需要补充导数与叉积。
- **目标**：识别直线、圆、平面和圆柱面，通过参数取得点、切向与几何法向；区分支撑几何与有限拓扑对象。
- **本周边界**：在给定基本模型上读取和采样；不要求独立构造边界，也不处理投影、求交。法向先指曲面参数导数确定的几何法向，Face 方向的影响在 week04 展开。

**本周五题：**

1. Curve 与 Edge、Surface 与 Face 分别有什么区别？
2. 曲线参数 `t` 怎样确定位置，为什么通常不能把参数直接当作长度？
3. 曲面参数 `u/v` 怎样映射到三维，周期参数意味着什么？
4. 怎样通过一阶导数取得切向与几何法向，哪些位置可能无法确定方向？
5. 怎样区分支撑几何的参数范围与拓扑对象限定的范围，并正确处理位置变换？

**独立练习**：识别四类基本几何；在圆心为世界原点、法向为 +Z、参考 X 方向为 +X 的半径 10 mm 圆，以及世界原点起始、轴向为 +Z、参考 X 方向为 +X 的半径 10 mm、高 20 mm 圆柱上取样。记录圆的 `t=0`、`π/2`、`2π` 与圆柱面的 `(u,v)=(π/2,5)`，绘制采样点、切向和几何法向；保留导数向量及归一化后的方向供比较。

**验收**：圆上 `t=π/2` 的点约为 `(0,10,0)`，单位切向约为 `(-1,0,0)`，导数模长约为 10；`t=0` 与 `2π` 的位置相同。圆柱面对应点约为 `(0,10,5)`，由 `∂S/∂u × ∂S/∂v` 得到的单位几何法向约为 `(0,1,0)`。能解释本例中圆的角参数用弧度，圆柱轴向参数按 mm 约定；归一化前检查导数或叉积是否退化。留下几何类型、采样数值和图元对照，不能把参数区间或 UV 外包范围直接当成 Face 的真实边界。

**下一周动机**：支撑几何说明形状怎样计算，但不能单独说明对象如何连接；下一周研究拓扑层级、身份、共享与邻接。

### week03：拓扑层级、共享对象与邻接关系

- **承接与前置**：已能读取几何类型和参数；本周研究有限对象如何连接，需理解容器、遍历和去重。
- **目标**：解释 Vertex、Edge、Wire、Face、Shell、Solid 的职责，按拓扑身份统计对象，并建立边到面的关联查询。
- **本周边界**：学习读取已有拓扑，不开展布尔或拓扑修复；样例长方体由本周独立生成，不读取其他周产物。

**本周五题：**

1. Vertex、Edge、Wire、Face、Shell、Solid 分别承担什么职责？
2. 为什么遍历出现次数与去重后的对象数量不同？
3. 共享拓扑对象与坐标重合有什么区别？
4. `IsPartner`、`IsSame`、`IsEqual` 分别比较什么，方向和位置怎样影响判断？
5. 怎样建立边到面的关联查询，并区分使用次数与不同相邻面的数量？

**独立练习**：遍历一个长方体，分别统计按各面边界出现的边及去重后的边，输出每条边关联的不同面。再比较 `TopoDS_Shape` 的两份普通赋值引用与两次独立构造的同尺寸、同位置长方体；保留部分共享边在两个面中使用时的方向，说明去重为何不等于删除方向信息。

**验收**：单个长方体有 8 个去重顶点、12 条边、6 个面、1 个实体；按六个面的四条边统计共 24 次边使用，每条边关联两个不同面。两份赋值引用不会增加去重后的对象数；两份独立构造的同位长方体合并统计得到 16 顶点、24 边、12 面，不因坐标相同自动共享。能够解释 `IsPartner` 只比较底层 TShape，`IsSame` 还比较 Location、忽略 Orientation，`IsEqual` 再比较 Orientation；本周默认去重采用 `IsSame` 口径。留下遍历/去重对照、边面邻接表与身份判断记录。

**下一周动机**：边被哪些面使用已经清楚，接下来观察每次使用如何在曲面参数域中表达边界，并理解方向、孔和周期接缝。

### week04：面边界、方向、pcurve 与基础检查

- **承接与前置**：已有几何参数、导数、拓扑层级和边面邻接；本周把每次边使用与所属面的参数域联系起来。
- **目标**：读取外环、内环和方向，解释三维曲线与 pcurve 的关系，观察周期接缝，并区分容差、有效性与设计预期。
- **本周边界**：读取给定带孔平面和基本圆柱样例，不训练手工造面、求交、分割或修复；不要求提前实现专用 UV 视图。后续实施时样例在本周自包含提供，不从其他周加载。

**本周五题：**

1. 支撑曲面与 Face 边界环怎样配合，外环和内环怎样表达孔？
2. Edge、Wire、Face 的方向怎样配合，为什么不能只看屏幕上的顺逆时针？
3. pcurve 怎样把曲面参数域中的边界映射回三维？
4. 为什么圆柱面的同一条接缝边可能在一个面中出现两次？
5. 对象容差和有效性检查分别说明什么，检查通过还不能证明什么？

**独立练习**：观察位于 XY 平面的给定 Face：外边界为 `[0,40]×[0,30] mm` 矩形，内边界为圆心 `(20,15)`、半径 5 mm 的圆。读取支撑平面、边界环、拓扑使用方向和容差；对具有三维曲线、已确认 `SameParameter` 的样例边，选取有效区间内至少 5 个参数，应用各自 Location 后比较 `C₃D(t)` 与 `S(pcurve(t))`。另在 week02 同规格的圆柱样例中读取侧面接缝的两次使用及其 pcurve；对比几何法向和 Face 使用方向。

**验收**：

- 带孔面有一个外环、一个内环，面积约为 `1200−25π ≈ 1121.460184 mm²`；它是 Face，不是 Solid，不能用实体体积验收。
- 留下参数、UV、两路三维位置、最大偏差和对象容差对照；解释参数一致性与位置变换的前提，不通过统一放大容差掩盖偏差。采样一致是本次观察证据，不能证明整条曲线在所有参数上都一致。
- 记录圆柱接缝的两次边使用、两条参数域表示及其共同三维位置；它在该样例中只关联一个不同面，不能把长方体的“两相邻面”规律套用到接缝。
- 输出有效性检查结果，解释方向反转不等于支撑曲面改变，也不单独决定模型无效；检查通过仍需核对尺寸、面积、边界和用途。

**下一月动机**：已经能读取现成面的边界，第二个月转向主动构造：从边与边界环建立带孔面，再研究拉伸、旋转、扫掠、放样、缝合及实体形成。

### week01：从边构造边界，再由边界构造面

- **承接与前置**：第一月已能读取给定带孔面的边界、方向和 pcurve；本周主动建立顶点、边与边界环。
- **目标**：从边构造矩形及带圆孔的平面 Face，区分构造成功、拓扑有效和边界符合设计。
- **本周边界**：使用现有 OCCT 构造接口，不引入求交、布尔或修复；闭合、共面、边界方向和区域含义都要检查。

**本周五题：**

1. 怎样从顶点构造边，再将边组织成 Wire？
2. 边界的连接、顺序与闭合分别意味着什么，坐标重合是否足够？
3. 从 Wire 构造平面 Face 需要满足哪些条件，闭合为什么还不够？
4. 外环、内环与方向怎样共同表达圆孔？
5. 怎样用构造状态、区域分类、面积和有效性检查验收结果？

**独立练习**：以共享角点构造 XY 平面 `[0,40]×[0,30] mm` 矩形的四条边，组织为闭合 Wire，再构造矩形 Face。加入圆心 `(20,15)`、半径 5 mm 的圆孔，记录环的方向；保留顶点/边、Wire、矩形面、带孔面各阶段。比较缺少闭合边、内环方向错误、圆孔越界等输入，记录在哪里拒绝或在哪项验收不符合设计，不把 `IsDone()` 当作完整验收。

**验收**：矩形面积为 `1200 mm²`；带孔面有一个外环、一个内环，面积约为 `1200−25π = 1121.460184 mm²`。圆孔中心为 OUT，材料点 `(5,5)` 为 IN；缺少闭合边或孔越界不能被标为符合目标的面。错误内环方向通过区域、面积和检查结果定位，再纠正构造。能够解释 MakeWire 可能在容差内处理连接，坐标相同不等于天然共享；闭合边界也可能不共面或自交。留下构造状态、阶段模型和区域/面积证据。

**下一周动机**：边界已能限定有限截面，下一周把 Edge、Wire、Face 作为输入，观察拉伸和旋转生成的不同维度与拓扑结果。

### week02：拉伸与旋转——输入类型决定生成什么

- **承接与前置**：已经能够构造有限截面，利用第一月的坐标变换与拓扑读取能力观察升维构造。
- **目标**：区分 Edge、Wire、Face 输入，构造带贯通孔的拉伸体和简单回转体，验收有限实体而非只看显示形状。
- **本周边界**：使用有限非退化样例；拉伸距离取正、回转角为非零且不超过 360°，回转截面避开轴。贯通孔直接由带孔 Face 生成，布尔切除留到第四个月。

**本周五题：**

1. 拉伸和旋转分别怎样从输入对象生成更高维对象？
2. 为什么拉伸 Edge、Wire 和 Face 通常分别得到 Face、Shell 和 Solid？
3. 拉伸方向、距离、旋转轴和角度怎样限定结果？
4. 带孔截面的孔如何传播到生成实体，完整旋转与部分旋转有何区别？
5. 怎样结合结果类型、封闭性、实体数量、有效性和体积验收？

**独立练习**：独立重建 week01 同规格的带孔 Face，沿世界 +Z 拉伸 20 mm，保留输入、侧面与结果对照。另在 XZ 平面构造 `x∈[10,15]、z∈[0,20] mm` 的矩形 Face，绕世界 Z 轴按右手规则分别旋转 360°、90°。先用简单非退化 Edge、闭合 Wire 与 Face 对照输入类型，再解释生成面的来源、端部封闭和孔边界。

**验收**：带孔拉伸体为一个有效有限实体，体积约为 `(1200−25π)×20 = 22429.203673 mm³`；完整回转体为一个有效有限实体，体积约为 `π(15²−10²)×20 = 2500π = 7853.981634 mm³`，90° 结果约为 `625π = 1963.495408 mm³`。对照输入类型与输出拓扑，不把类型标签或 `IsDone()` 单独当作成功证据；记录封闭性、实体数量、有效性与体积。零距离、零角度或其他不符合本课前置的输入应被明确拒绝，不能被标为目标三维实体；不固定所有结果的面数。

**下一周动机**：拉伸和旋转只有一条生成规律，下一周把截面沿路径移动，或用多个截面限定形状，研究方向与对应关系的影响。

<a id="month02-week03"></a>

### week03：扫掠与放样——路径、截面及对应关系

- **承接与前置**：已经理解截面类型与升维构造；本周使用路径和有序截面族，补充截面放置与对应关系。
- **目标**：分别完成简单扫掠和放样案例，解释路径条件、截面方向、顺序与起始点的影响。
- **本周边界**：主练习使用直线路径和两截面的直纹放样，光滑圆弧路径作为扩展；不展开复杂角点过渡或曲面拟合推导。

**本周五题：**

1. 扫掠中的截面与路径各决定什么，怎样放置初始截面？
2. 截面沿路径运动时方向怎样变化，路径不光滑会带来什么问题？
3. 放样如何连接多个截面，截面顺序、起始点和方向为什么重要？
4. 扫掠的截面类型、放样的实体选项怎样影响 Shell/Solid 结果？
5. 怎样识别扭转、错误对应和失败，算法的兼容处理又改变了什么？

**独立练习**：在 XY 平面放置中心为原点的 4×2 mm 矩形 Face，其法向与起始路径切向均为 +Z，沿 +Z 的 30 mm 直线路径扫掠。另在 z=0、z=30 mm 处放置中心对齐、方向与角点对应一致的 4×2 mm、8×4 mm 矩形 Wire，以直纹放样构造实体。把路径长度改为 45 mm；再改变一个放样截面的起始角点，对比兼容处理开启与关闭时的对应和结果。保存截面、路径和生成形状。

**验收**：直线扫掠得到一个有效有限实体，体积为 `4×2×30 = 240 mm³`；路径改为 45 mm 后为 `360 mm³`。对齐的相似矩形直纹放样体积为 `30/3×(8+32+√(8×32)) = 560 mm³`，结果为一个有效有限实体。用 Shell/Solid 对照解释扫掠截面类型与放样实体选项；记录截面顺序、起始点、兼容设置、检查和体积。不把改变起始点必然产生扭转写死为预期，允许算法重排或拒绝，但必须用实际对应或失败信息解释。基础 MakePipe 案例使用满足 G1 条件的路径，带尖角路径不作为默认成功样例。

**下一周动机**：能够生成面片之后，还需判断面片怎样连接、是否平滑、能否围成有限体积；下一周分别研究连续性、缝合、壳和实体。

### week04：曲面连接、缝合与实体形成

- **承接与前置**：已经能够生成面和实体，结合第一月的共享边、方向、导数与法向，研究面片连接的不同性质。
- **目标**：区分几何连续、拓扑缝合、壳封闭和实体有效，完成闭壳与缺面开壳的对照。
- **本周边界**：使用解析平面和几何吻合的面片，缝合只是基础构造；不通过扩大容差、自动修复或拟合把问题隐藏起来。

**本周五题：**

1. 位置连续 G0 与切向连续 G1 分别要求什么，为什么不能直接等同于参数连续 C1？
2. 怎样沿公共边比较位置与切平面，Face 方向为何会影响法向比较？
3. 缝合改变了哪些拓扑关系，为什么不自动保证曲面平滑？
4. 连通壳、封闭壳与有限实体有什么区别，怎样检查自由边和方向？
5. 为什么 MakeSolid 或有效性检查通过，仍不能单独证明得到预期有限实体？

**独立练习**：在 XY 平面以 `x=20、y∈[0,30] mm` 为接缝，比较左片 `x∈[0,20]` 与右片 `x∈[20,40]` 的共面连接；再将右片绕该接缝的 +Y 方向旋转 30°，沿接缝比较位置和法向。另准备六张互不共享拓扑、几何位置对应 40×30×20 mm 长方体边界的独立矩形面，缝合后检查闭壳，再构造实体；去掉顶面重做，记录自由边和开放壳。所有面在本周独立构造或逐面深复制，不直接把已共享边的完整长方体当作待缝合输入。

**验收**：两组平面沿接缝位置均一致；共面组切平面一致，折角组夹角约 30°。区分几何法向与拓扑使用法向，反向法向本身不代表切平面不连续；一般曲面有限采样不能替代全域连续性证明。六面样例缝合后无自由边、形成闭壳，再得到方向正确、有效的有限实体，体积约 `24000 mm³`；缺顶面样例留下四条自由边，不能被当成本课目标的有限实体。记录缝合前后共享关系、结果类型、自由边、封闭性、方向、有效性和体积；缝合成功不等于已经平滑或已经成实体。

**下一月动机**：已经能主动构造边界并检查连接，第三个月转向两个已有模型之间的关系：投影、求交，以及交线怎样成为正确的有限裁剪边界。

### 第二月末验收与阶段边界

能够从输入讲到输出，解释同一轮廓作为 Wire 和 Face 输入为何产生不同结果，带孔面怎样生成贯通孔实体，以及扫掠、放样受哪些路径和截面条件影响。分别判断几何连续、拓扑共享、壳封闭与有效有限实体，不用一个“成功”状态概括所有条件。

每周保留输入参数、中间模型、检查结果和至少一个变体或失败案例。解析面积/体积、拓扑关系与设计意图共同构成证据；不把可能随算法分解变化的面数当作普遍规则。OCCT 允许开放外壳描述无限实体，MakeSolid 不自动完成一致性验证；即使返回 Solid 或 `IsDone()` 为真，仍须验证本课要求的封闭性与有限体积。

本月使用 OCCT 现有构造能力，不展开 B 样条拟合推导、求交裁剪、布尔或系统修复；尖角过渡和复杂曲面构造也不列入基础验收。第二月当前为目标规划，代码与完整五题讲义尚未实现。

## 独立构建与运行

工具链为 **Clang + CMake + Ninja + clangd**。模板采用 C++23、`import std;`、Qt Widgets 与 OCCT；每个 week 复制一份完整框架源码，各自构建，不引用其他周代码或产物。

开发与验证环境：Linux Fedora 44（内核 `7.2.11-200.fc44.x86_64`，x86_64）。OCCT 版本 **8.1.0**，预编译安装位于本仓库根下的 [`occt/`](occt/) 目录（含 `include/`、`lib/`、`bin/`、`share/`，各周共用）；该目录已被 `.gitignore` 排除，不随仓库分发，按各周 tools 文档安装。

在任意 `month01/weekYY/` 目录执行 `./run.sh`，或 `./run.sh --headless`；程序默认运行本周实验。每周自带 tools 文档、CMake/IDE 配置和本地 build。新课程的复制入口仍为 `template/week-template/`。
