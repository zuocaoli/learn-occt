# 第一月第二周：曲线、曲面与参数采样

## 本周训练

- **承接与前置**：已有[第一周](../week01/README.md)的坐标、变换和单位约定；按需补充导数与叉积。
- **目标**：识别直线、圆、平面、圆柱面，读取参数范围，计算位置、切向和几何法向。
- **独立练习**：半径 10 mm、法向 +Z、参考 X 为 +X 的圆采样 t=π/2；同坐标架圆柱采样 (u,v)=(π/2,5)，再改变半径和角度。
- **验收**：圆点约 (0,10,0)、单位切向 (-1,0,0)、导数模长 10；圆柱点 (0,10,5)、单位几何法向 (0,1,0)。

## 1. Curve 与 Edge、Surface 与 Face 分别有什么区别？

Geom 曲线/曲面描述参数如何生成空间位置；Edge/Face 在此之上增加有限范围、方向和连接。实验中的支撑直线、平面以及圆柱轴向不受有限边界限制，显示的 Edge/Face 却有边界。圆是周期几何，一个闭合 Edge 仍需端点和范围表示；不能把图像上闭合就当成拓扑共享已成立。

## 2. 曲线参数 t 怎样确定位置，为什么通常不能把参数直接当作长度？

C(t) 给出位置，C′(t) 给出导数。标准直线本例的 t 按长度，圆的 t 是弧度，圆弧长增量为 R·Δt；圆半径 10 时导数模长为 10，不是单位切向。先判断导数非退化，再归一化取得方向。程序使用 OCCT 8 的 `EvalD1()` 返回点与一阶导数；它与传统 `D1()` 的数学含义一致。

## 3. 曲面参数 u/v 怎样映射到三维，周期参数意味着什么？

平面本例 S(u,v)=(u,v,0)；圆柱 S(u,v)=(R cos u,R sin u,v)，所以角参数 u 使用弧度，轴向 v 使用本课 mm 约定。u 与 u+2π 对应同一位置，不代表两条边自动共享。有限圆柱面只取 v∈[0,height]，程序拒绝超出该范围的所选采样；实际带孔面的边界不能仅由 UV 最小/最大值表示。

## 4. 怎样通过一阶导数取得切向与几何法向，哪些位置可能无法确定方向？

曲线单位切向为 C′/|C′|；曲面几何法向来自 Su×Sv 的归一化。导数或叉积为零、曲线/曲面连续性不足时，方向可能不存在，不能直接构造 gp_Dir。实验先检查模长，图元箭头使用单位方向再乘显示长度；该显示长度不是导数模长。本周只计算几何法向，拓扑 Face 反向的含义在第四周展开。

## 5. 怎样区分支撑几何的参数范围与拓扑对象限定的范围，并正确处理位置变换？

BRepAdaptor 可读取有限 Edge/Face；底层 Geom 对象可能无界。`BRep_Tool::Curve(edge, location, first, last)` 返回局部几何与位置，点、导数转换到世界坐标时要正确应用一次 Location。第五阶段把圆平移 25 mm，局部点仍约 (0,10,0)，世界点为 (25,10,0)，并与已处理 Location 的 BRepAdaptor 结果独立对照，避免漏乘或重复乘。

## 代码与执行轨迹

[experiments/course.cpp](experiments/course.cpp) 提供五阶段：直线 Edge、圆采样、平面 Face、圆柱面采样、Located 圆。圆周所有采样参数与位置输出到日志；所选点、切向、法向以图元展示。面和边的构造只是本周自包含样例，不作为构造算法练习。

```text
直线 t=5 → (5,0,0)，Edge 范围 [0,20]
圆 t=π/2 → (0,10,0)，|D1|=10
平面 (10,5) → (10,5,0)，法向 +Z
圆柱 (π/2,5) → (0,10,5)，法向 +Y
Located 圆 → 世界点 (25,10,0)
```

## 独立构建与运行

工具链 **Clang + CMake + Ninja + clangd**，C++23、`import std;`。本周自带完整框架、模型和构建配置，只共用第三方 `../../occt`。依赖版本、IDE、离屏与真实视窗验收见 [tools/README.md](tools/README.md)。在本周目录执行：

```bash
./run.sh
./run.sh --headless --param radius=20 --param angle_deg=180
cmake --preset default
cmake --build --preset default
ctest --preset default --no-tests=error
./build/demo --headless --output build/results/sampling
```

默认实验 `geometry-sampling`；报告保存样本、参数与测量。`--param height=1` 在默认 axial=5 时应失败；`--param radius=0` 在入口拒绝。模型检查有效不代替采样正确，[course-tests](tests/course_tests.cpp) 独立核对解析预期、周期、Location 及变体。
