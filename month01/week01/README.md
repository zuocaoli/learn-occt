# 第一月第一周：坐标、变换与模型观察

## 本周训练

- **承接与前置**：从参数化矩形进入三维长方体；会使用 C++ 类和基本三角函数。
- **目标**：区分点、向量、方向、坐标系和相机；预测并验证刚体变换顺序。
- **独立练习**：对 40×30×20 mm 长方体，比较先沿世界 X 平移 50 mm 再绕世界原点 Z 正向旋转 90°与相反顺序，先预测再运行。
- **验收**：原始角点 P=(40,0,0) 分别约为 (0,90,0)、(50,40,0)，体积均约 24000 mm³；保存重载后位置保持，相机操作不改模型。

## 1. 点、向量和方向分别表示什么，为什么不能混用？

`gp_Pnt` 表示位置；两点之差是 `gp_Vec`，表示有长度的位移；`gp_Dir` 表示归一化方向，零向量不能构造方向。平移会改变点，不改变自由向量；旋转同时改变点和向量。把三者都当三元数而忽略语义，容易把平移错误地加到方向上。

## 2. 坐标系怎样定义位置，局部坐标与世界坐标有什么关系？

坐标要连同原点和基向量解释。实验给出局部原点 (5,10,0)、局部 X 指向世界 +Y，局部点 (2,0,0) 对应世界 (5,12,0)，局部向量 (1,0,0) 只旋转成 (0,1,0)。`gp_Ax3` 描述坐标架；本例 `SetDisplacement` 将标准架移动到局部架的世界位置，不能与进行坐标换算的 `SetTransformation` 混为同一方向。

## 3. 平移、旋转与相机操作分别改变什么？长度和角度采用什么约定？

模型变换生成新的 BREP 形状；视图操作只改变观察相机。本例坐标约定 mm、体积 mm³，OCCT 不自动附加单位。面板角度为度，进入 `gp_Trsf::SetRotation` 前转成弧度。模型变换可能通过几何或 Location 表达；不能仅凭 Location 矩阵是否非单位就断言模型没移动，应检查实际几何位置。

## 4. 变换顺序、旋转轴和旋转中心为什么会影响结果？

`R*T` 从右向左作用，先平移再旋转，平移后的偏移也被旋转；`T*R` 则沿固定世界 X 平移已旋转的点，所以结果通常不同。代码固定绕世界原点的 +Z 轴按右手规则旋转，不能偷偷改成绕零件中心。`BRepBuilderAPI_Transform(..., true)` 复制结果，原始输入不被后续阶段改写。

## 5. 怎样通过坐标、体积及 BREP 保存重载证明变换正确？

每阶段记录变换参考点、向量和体积，测试再从结果 BREP 遍历顶点，验证记录点确实在模型上。刚体变换保持距离与体积，两个分支都保持有效性。BREP 读写后重新检查位置与体积，不要求文件逐字节相同。坐标比对允许 1e-9 mm 数值误差，这是本练习阈值，不用于放大模型容差。相机不写入核心阶段模型。

## 代码与执行轨迹

主要代码：[experiments/course.cpp](experiments/course.cpp)；验收：[tests/course_tests.cpp](tests/course_tests.cpp)。

```text
01 原始 → P=(40,0,0)
02 A 平移 → P=(90,0,0)
03 A 再旋转 → P≈(0,90,0)
04 B 旋转 → P≈(0,40,0)
05 B 再平移 → P≈(50,40,0)
```

每阶段都可在视窗和树中选择。点为 P，箭头是变换后的 X 向量；初始阶段还有局部架参考。拓扑统计先观察，去重机制在第三周展开。

## 独立构建与运行

工具链 **Clang + CMake + Ninja + clangd**，语言 **C++23、`import std;`**。本周完整复制框架，第三方 OCCT 读取 `../../occt`，不依赖其他周。依赖版本、IDE 与真实视窗测试见 [tools/README.md](tools/README.md)。在本周目录执行：

```bash
./run.sh
./run.sh --headless --param angle_deg=0
cmake --preset default
cmake --build --preset default
ctest --preset default --no-tests=error
./build/demo --headless --output build/results/order90
./build/demo --input build/results/order90/step-2-object-0.brep
```

默认实验 `transform-order`；`--experiment box-transform` 可运行框架基础示例。输出目录需为空或不存在，报告保存实际参数、阶段、坐标及复现命令。离屏 Qt 测试不代替真实视窗；鼠标选取和相机操作见 tools 文档。
